Warum keine fertigen Unity-Dateien beiliegen

Das Skriptformat von SIGMA Unity ist in keiner öffentlichen Unterlage beschrieben. Geprüft wurden Broschüre, Produktseite, FAQ, Tutorienliste und die Handbücher der Lastbankserien. Auch das Installationspaket der Software gibt das Format nicht her.

Ein geratenes Format würde auf der Baustelle genauso scheitern wie die .tst-Dateien. Deshalb enthält dieses Dokument die Programme als Schritttabellen, die sich in jeden Testeditor eintippen lassen, und auf Seite 2 steht, was gebraucht wird, um die Dateien doch noch automatisch zu erzeugen.

Zusätzlich im Ordner

Zu jedem Programm liegt eine CSV-Datei bei, Trennzeichen Semikolon, mit denselben Spalten wie die Tabellen hier. Falls Unity einen Import für Tabellen hat, ist das der schnellste Weg.

1  Erst diese fünf Minuten, bevor irgendwas abgetippt wird

Es kann sein, dass das Problem klein ist. Diese Punkte in dieser Reihenfolge prüfen.

1
Welchen Dateityp bietet der Öffnen-Dialog an? In Unity den Dialog zum Laden eines Testprogramms öffnen und das Auswahlfeld für den Dateityp aufklappen. Dort stehen die Endungen, die Unity erwartet. Diese Endungen notieren und mir schicken. Steht dort .tst, liegt das Problem im Inhalt. Steht etwas anderes dort, liegt es an der Endung.
Notiert:
2
Gibt es eine Importfunktion für alte Programme? In den Menüs Setup und Settings nach Import, Legacy, Migrate oder SIGMA PC suchen. Unity fasst PC Basic, Network Pro und PC System zusammen, eine Übernahme ist denkbar.
3
Wo legt Unity seine eigenen Programme ab? Ein kleines Testprogramm mit drei Schritten in Unity anlegen und speichern. Dann im Dateisystem suchen, wohin es gespeichert wurde. Typische Orte sind der Installationsordner, ProgramData oder Dokumente.
4
Die mitgelieferten Vorlagen ansehen Der Hersteller nennt als Merkmal in-built load test templates. Diese Vorlagen liegen als Dateien auf dem Rechner. Ordner suchen und Inhalt ansehen.

Das Eine, was alles löst

Schick mir eine einzige in Unity gespeicherte Testdatei, egal wie klein, oder den Inhalt des Vorlagenordners. Damit kann ich das Format Zeichen für Zeichen nachbilden und alle sechs Programme in einem Durchgang erzeugen, so wie bei den .tst-Dateien.

Ebenfalls hilfreich: ein Bildschirmfoto des Öffnen-Dialogs mit aufgeklapptem Dateityp, und ein Foto der Fehlermeldung, die beim Laden einer .tst-Datei erscheint. Der genaue Wortlaut der Meldung sagt, woran es scheitert.

Wenn nichts davon hilft

Avtron Support fragen, mit der konkreten Frage: Can SIGMA Unity import load test programs created in SIGMA PC, file extension .tst? If not, what is the native test script format and is there a documented structure?
customercare@avtronpower.com, +44 1780 480033. Software-Version V1.04.89 angeben.

Reihenfolge beim Abtippen

Falls alles von Hand eingegeben werden muss, nicht alle sechs auf einmal. P02 zuerst, 23 Schritte, das ist die vertraglich geforderte Rampe und der Kern der Beanstandung. Danach P01 für die Schrittzeitmessung. Der Rest kann warten, bis das Format steht.

Beim Eintippen beachten

  • Arbeitsgrössen auf kW und cos φ stellen, nicht auf Prozent. Die Sollwerte sind krumm, zum Beispiel 2298 kW.
  • cos φ ist in allen Programmen durchgehend 1,00.
  • Die Spalte Prozent ist nur zur Kontrolle da, bezogen auf 2750 kW.
  • Haltezeit ist die Zeit nach dem Schaltbefehl, bis der nächste Schritt kommt.
  • Supply on Test vorher eintragen, sonst stimmen die Prozentwerte der Software nicht.
