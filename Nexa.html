Nexa Cloud einrichten
Verbinde dein Supabase-Projekt für Mitarbeiter-Logins und gemeinsame Daten.
Beide Werte stehen in Supabase unter Settings → API Keys (bzw. oben auf Connect). Nimm den anon / public-Key (beginnt mit eyJ… oder sb_publishable_…) — er ist öffentlich und sicher, der Schutz läuft über Row-Level-Security. Beim Klick auf „Verbinden & testen" prüft Nexa die Verbindung und sagt dir genau, falls etwas fehlt.
① Einmalig: dieses SQL in Supabase ausführen
Supabase → SQL Editor → einfügen → Run. Legt die gemeinsame Tabelle an und aktiviert Live-Sync.
create table if not exists public.crm_state (
  id text primary key default 'default',
  data jsonb not null default '{}'::jsonb,
  updated_at timestamptz default now(),
  updated_by text
);

alter table public.crm_state enable row level security;

create policy "team read"   on public.crm_state
  for select to authenticated using (true);
create policy "team insert" on public.crm_state
  for insert to authenticated with check (true);
create policy "team update" on public.crm_state
  for update to authenticated using (true) with check (true);

alter publication supabase_realtime add table public.crm_state;
