Datenbank-Tabelle anlegen

Links in der Supabase-Seitenleiste den SQL Editor öffnen (Symbol >_), „New query" klicken, das untenstehende SQL einfügen und auf RUN drücken.

SQL — einmalig ausführen 
create table if not exists public.crm_state (
  id text primary key default 'default',
  data jsonb not null default '{}'::jsonb,
  updated_at timestamptz default now(),
  updated_by text
);

alter table public.crm_state enable row level security;

create policy "team read"   on public.crm_state
  for select to authenticated using (true);
create policy "team insert" on public.crm_state
  for insert to authenticated with check (true);
create policy "team update" on public.crm_state
  for update to authenticated using (true) with check (true);

alter publication supabase_realtime add table public.crm_state;
✅
Richtig, wenn unten „Success. No rows returned" erscheint. Die letzte Zeile aktiviert den Live-Sync zwischen den Mitarbeitern.

Anmelden

Live-Sync testen: In einem zweiten Browserfenster mit einem anderen Mitarbeiter-Login anmelden, einen Kontakt anlegen → er erscheint beim anderen automatisch. ✅

Auf Netlify live stellen:

  1. Nexa.html zu Netlify hochladen — am besten in index.html umbenennen, dann läuft sie direkt unter der Domain.
  2. In Supabase die Site URL (Schritt 3) auf die echte Netlify-Adresse setzen.
  3. Fertig — jeder Mitarbeiter öffnet die URL, meldet sich an, alle arbeiten auf denselben Daten.
🔎
Kontrolle in Supabase: Table Editor → crm_state — dort liegt eine Zeile id = default, im Feld data stehen alle CRM-Daten.

„Geht nicht?" – Fehler & Lösungen

Nexa zeigt beim „Verbinden & testen" bzw. beim Login eine Klartext-Meldung. Hier die Bedeutung:

⚠️
„…die Tabelle crm_state fehlt" → Schritt 1 wurde nicht (komplett) ausgeführt. SQL erneut im SQL-Editor einfügen und Run drücken.
❌
„Der Key wird abgelehnt (ungültig)" → Falscher oder unvollständiger Key. Den kompletten anon / public-Key kopieren (Schritt 2). Nicht den service_role-Key.
❌
„Keine Verbindung möglich" → Project URL falsch getippt oder keine Internetverbindung. URL muss exakt https://…supabase.co lauten (ohne Schrägstrich am Ende).
📧
„E-Mail noch nicht bestätigt" → In Schritt 3 „Confirm email" ausschalten, oder die Bestätigungs-Mail im Postfach öffnen.
🔑
„E-Mail oder Passwort falsch" → Zugang in Supabase unter Authentication → Users prüfen; ggf. neuen User anlegen.
🔄
Daten syncen nicht live → Die letzte SQL-Zeile (alter publication supabase_realtime …) muss gelaufen sein. Notfalls einzeln nachträglich ausführen.
⚙️
Falsche Daten eingegeben? Im Nexa-Login unten auf „⚙ Cloud-Einstellungen" klicken und URL/Key neu eingeben.
🌐
„Cloud-Bibliothek nicht geladen" → Internet/Firewall blockiert das CDN. Mit Internetverbindung neu laden, oder vorerst „nur lokal nutzen".
